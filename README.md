# 🏡 Georg & Filippa Hub

En felles webapp for å gjøre hverdagen som samboere litt enklere og mer oversiktlig.

Målet er å samle praktiske ting som økonomi, middagsplanlegging, handling og husarbeid på ett sted, slik at begge har oversikt og ingenting blir glemt.

## Funksjonalitet

- **Utlegg:** Registrere felles utgifter og holde oversikt over hvem som har betalt.
- **Middager:** Planlegge middager for uken.
- **Handleliste:** En felles handleliste som begge kan oppdatere.
- **Husarbeid:** Fordele oppgaver og holde oversikt over hva som er gjort.
- **Butikkturer:** Registrere og holde oversikt over handleturer.

## Teknologi

- React + TypeScript
- Vite
- React Router
- Node.js + TypeScript
- PostgreSQL

## Kom i gang

Klon prosjektet:

```bash
git clone https://github.com/georgob02/ApartmentHub.git
cd ApartmentHub
```

Installer avhengigheter i frontend og backend:

```bash
cd frontend
npm install

cd ../backend
npm install
```

Opprett nødvendige miljøvariabler i `.env` før du starter applikasjonen.

## Mål

- Samle hverdagslogistikken på ett sted.
- Gjøre planlegging enklere.
- Skape bedre oversikt over felles økonomi.
- Fordele ansvar og oppgaver på en ryddig måte.
- Ha en enkel og brukervennlig løsning som fungerer godt på mobil.
